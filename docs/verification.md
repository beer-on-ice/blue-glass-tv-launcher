# v1.1.0 验证记录

日期：2026-10-23。设备：Sony X9000H / BRAVIA VH1，国行 Android 10 / API 29。

## 构建

使用 JDK 21、Android SDK 34、AGP 8.5.2、Gradle 8.9 执行：

```bash
./gradlew --no-daemon testReleaseUnitTest lintRelease assembleRelease
```

结果：构建成功；17 项 JVM 测试通过；Lint 0 个错误、8 个警告。Release APK 已验证签名并覆盖安装成功。
